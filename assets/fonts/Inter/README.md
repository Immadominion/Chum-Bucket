# Bundled sheet typeface: Inter

Inter is the face the original Chumbucket app shipped with, and the closest
match to the reference sheet comp
(`assets/images/open_sourced_design_inspiration/irfan/img2.jpeg`). Bottom-sheet
headers, sheet actions and the resolve sheet use it so the sheet reads like the
comp. PP Neue Machina and Montserrat elsewhere are unchanged.

Unmodified static Regular (400), Medium (500), SemiBold (600), Bold (700) and
ExtraBold (800),
matching `google_fonts 8.1.0`. The package discovers these asset filenames
before attempting HTTP fetching, so nothing is downloaded on first launch.

Source: `https://fonts.gstatic.com/s/a/<sha256>.ttf`, using the exact descriptor
hashes and lengths from the locked package's Inter entry.
